# 博主入门、发现卡片与双语社区

新用户入口从现有 `/kol/discover` 的已核实观点中挑选最多六位未关注博主，优先当前语言，
要求近 60 天内的发布日期、可读文本和精确来源。头像轻浮动，悬停/聚焦暂停，支持减少动态效果。
点头像预览；阅读及明确关注成功后均保留 creator、post、point，进入那条已就绪来源。
不硬编码博主名称，不增加模型调用，不声称全量历史已回填。

发现卡片默认展示作者、方向、股票、观点和日期。长条件与期限折叠，展开后保留全部来源措辞。
移除截断卡片的固定高度滚动框，初始六张，按需显示更多；手机为单列。
筛选标签与控件在桌面间隔 18px，手机垂直间隔 10px，焦点边框不会遮住标签。
摘要统计缺失与实际零区分；全局 feed 未包含某位博主的内容时不推断其拥有零摘要。
中文模拟页的英文装饰标题已本地化。

社区入口独立显示语言、反馈用途和产品演示说明：

- 中文：https://t.me/duckybotGroup（保留原群）
- 英文：https://t.me/duckybotGroupEN（新建公开群 Ducky Bot · English Community）

英文群保留当前账号为唯一初始成员，未自动邀请联系人。简介和公开链接已保存。
群头像上传因浏览器扩展文件权限未完成，暂用默认头像。
各语言 URL 通过配置和构建后的链接回归检查，避免英文站仍指向中文群。

验证：完整前端回归 517 tests 通过。使用生产公开来源快照、模拟新用户检查博主页，
未修改生产关注列表；七位近 60 天候选的 post/point 均通过后端只读精确匹配。
中英文四个博主标签页在 320px/390px 手机宽度检查无横向溢出；已检查长条件默认折叠、
英文页中文原文的按需展开、来源链接和键盘焦点。双语社区卡片完成桌面可视检查。
