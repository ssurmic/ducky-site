# Briefing navigation icon · 2026-09-06

The owner's iPhone screenshot showed the Briefing label with an empty icon slot. Read-only
production inspection confirmed that `/vendor/lucide/icons.svg` returned a year-long immutable
cache header and an older edge-cached payload without the `briefing` symbol, while the checked-in
sprite contained it. The shell's external `<use>` URL had no version; adding a symbol did not
change the cached resource address.

The build now embeds the shared local SVG symbols once in each app shell, with namespaced IDs.
Both template navigation and runtime app icons reference these in-page symbols. Symbol artwork
still comes from one local vendored file. No extra icon request, cache purge or user cache clearing
is required. Both language shells revalidate normally, and older retained module graphs are kept.

More) to actual local drawing elements in both built languages. Local browser visual checks cover
390px Chinese dark and 320px English light with the More menu expanded. All navigation icons render.
The local fixture used the actual built shell with scripts omitted and Briefing selected; production
verification follows after release. This does not claim a physical-iPhone test.
