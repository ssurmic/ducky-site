# 下一版 demo：自选股记忆、Vibe Check 与条件复现

状态：**脚本与 GLW 图已备好，等待功能验收后录制。** 本轮没有生成声音、影片或真实通知，也没有改动线上 demo。文件名沿用任务指定名称；产品正式名称采用最新确认的 **Vibe Check（社媒热度）**。Degen Signal / Sentiment 仅保留为内部历史检索别名，不进入新版客户画面或旁白。

时长口径：用户当前视频长度为约 **35–40 秒**。下文 116 秒分镜是展开案例的参考素材，供短片选段和详细演示使用，不是已批准替换短片的长度，也不是已制作的视频。两分钟仅为阅读简报的体验目标，尚未实测，不能当作已达成的 SLA。

## 用户看完应明白什么

用户选好关注股票，或明确提供持仓后，打开 brief，争取在两分钟内读懂最近一批资料里与自己有关的变化：发生了什么、为什么关联到这只股票、原始记录是什么、之前设的条件是否又出现，以及还有什么资料没拿到。**两分钟是理解这份简报的体验目标，不是全部来源两分钟内采集、处理或送达的 SLA。**

默认只展示日期、相关股票、一句变化和必要状态；点开后能看到原文、发布时间、首次收录、原始版本、后续价格和缺项。关注列表不等于持仓。用户未提供仓位时，只能说“与你关注的 GLW 有关”；不能算对其账户的盈亏影响。持仓数量、成本和账户关联必须等真实持仓功能验收后才能出镜。

Vibe Check 单独回答“讨论有没有异常变化”。它与原帖多空、价格走势和公司基本面分开，不能把热度当作估值、见顶概率或大众一致看法。没有历史热度就显示缺项，不能拿今天的分数贴到七月曲线上。

## 贯穿全片的画面

同一份示例自选列表贯穿：GLW、NOK、HOOD、BE、INTC。简报按股票归并相关事件，原始来源仍可逐条展开。开场可以像照顾孩子一样轻松，但不把用户说成无知，也不把系统说成不会漏事。

“所有数据流”验收要以实际启用来源清单为准，逐项留样，不能靠动画里画几条线证明全部接通。下面是录制清单，不是已完成接入声明。

| 资料组 | 应接到股票的事实 | 录制前要看到的证据 |
|---|---|---|
| 高管、机构、政治人物与集中买入 | 发行人、报告者、证券类别、交易日、披露日与金额口径 | 同一事实从来源→股票→brief，重复转载只算一个事件；BE/INTC 的配偶披露不改称本人交易 |
| 战略合作、AI 产业信息、招聘 | 合作条款、公司身份、供应链/业务关系及关系依据 | 直接相关和业务推断区分；不按关键词把不相关公司强行归类 |
| 价格、到价、超跌、K 指标、IV/HV、相对同业 | 当前条件、历史基准、计算版本与资料时间 | 缺价/过期/没有历史 IV 显式保留；条件复现保留规则版本 |
| 财报、宏观、流动性、市场与周历 | 事件意义、日程、相关业务影响 | 例如利率与 HOOD 利息收益率有公司披露依据；指数变动以官方公告为事实，不凭新闻标题确认 |
| 博主与 Vibe Check | 归属到作者的原文观点；有边界的讨论量 | 博主原文与热度分开展示；无原帖方向时不写“全网看多/恐慌” |
| 日报、盘前/收盘前、周报、brief | 上述事实的阅读入口 | 不把每份摘要当成一条新来源；原始记录和后续修订仍能追溯 |

若某个源没有当批覆盖，应显示“本次未覆盖 / 资料暂不可用”，不是 0 条事件。新增 BE 加入标普 500 的故事只有在官方指数事件适配器与股票归并通过后才替换录制占位；本稿不虚构其公告日、生效日或股价影响。

## 开始录制前的验收条件

1. **名称与真实入口：** 网站显示 Vibe Check，zh/en 和手机/桌面一致；不只是一张静态设计图。来源、时间、样本不足、过期、平台未接入都能按实际情况显示。
2. **来源到股票：** 对实际启用的每条数据流完成一次有依据的股票关联和 brief 归并；公司歧义、同名词、间接业务关系和缺主体的样例也要测。BE 指数事件必须有官方来源和公告/生效日期，不拿新闻转载取代官方确认。
3. **原始记录可回看：** 从 brief 返回不可变来源版本；事件/发表、首次收录、行情日期和处理时间分别保存。修订后仍能打开原版。补录数据不能变成当年的“已知/已发”。
4. **条件复现可实际走通：** 规则草稿由用户明确启用；一次经过隔离的测试里，让事实满足条件，证明它关联原事件和版本，再验证重复事件不重复打扰、规则变更失效、缺价不触发。需要展示送达时，必须有实际渠道回执；queued/失败不能写已送达。本轮没有发送这些测试通知。
5. **Vibe Check 含义可靠：** 注意力、原帖方向、价格和估值不混用。历史序列覆盖/分母/未成熟窗口可查，跌出榜单不当零；板块解释必须有适用范围依据。没有 X 数据就不展示 X 已覆盖。现有研究冻结规则不因录片降低门槛。
6. **预测与研究分开：** 若要宣称顶部预警有效，先完成冻结研究的封存测试、price-only 对照、误报漏报和所有亏损记录；没有完成就只讲讨论变化。录制热度功能本身不要求先证明预测效果，也不允许借机宣称效果。
7. **brief 阅读目标：** 用真实当批资料做一次有代表性的中英阅读检查，用户能在约两分钟内说清变化、相关性和缺项；这不推出采集 SLA。关注列表与真实持仓分别标识，账户隔离/API 权益门禁验证通过。
8. **录制验收：** 功能完成后再冻结资料→录屏→生成中英声音→按实际词组对字幕。先显示图的最终日期再说结果；完整曲线和亏损保留。手机画面分步聚焦价格、RSI、原始记录，不把整张 1920px 信息图缩小到手机后硬读。长短句与专名应试听，ASR 只作辅助。
